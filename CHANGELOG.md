# Changelog

## [0.4.0] - 2026-11-19
### Added
- SIPL grammar and typed AST parser with `SourceSpan` positions.
- Interpreter with variable state, step limit control, and JSON event trace.
- CLI runner (`sipl`) with JSON trace and Parse Tree export (`text`, `json`, `dot`, `svg`).
- GitHub Actions CI for linting, type-checking, tests, and package build.

## [0.1.0] - 2026-11-11
### Added
- Initial project setup and formal SIPL grammar.
